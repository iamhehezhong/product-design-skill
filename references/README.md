# Product Design Skill 资料库

这套资料用于支持 `product-design` skill。核心目标是让 Codex 在产品交互创新、设计产出和设计评审时，不只给出“好看”的方案，而是能稳定判断并生成更省认知、更省操作、更省视觉注意力，并且更有人性的产品设计。

## 核心判断

产品设计的第一性原则：

- 少用脑：用户不需要解释就知道怎么用。
- 少用手：用户不需要过多输入、配置、跳转和重复操作。
- 少用眼：界面简洁，一眼能看到重点。
- 有掌控：用户知道系统状态，能撤销、修改、恢复、接管。
- 有美感：视觉服务于理解、效率、情绪和品牌气质。
- 有人性：减少焦虑、打断、误导和被迫感。

- `01-basic-principles.md`：基础产品设计原则，包含少用脑、少用手、少用眼及掌控感等最高优先级判断。
- `02-classic-theories.md`：经典产品设计、交互设计、可用性、行为科学理论。
- `03-input-inventory.md`：正式做产品设计前应该收集哪些输入。
- `04-interaction-visual-aesthetics.md`：交互模式、视觉规范、美学与人性、Apple / iOS App 美学的统一判断资料。
- `05-ai-product-interaction.md`：AI 产品交互专项原则与检查项。
- `06-product-type-patterns.md`：按产品类型沉淀设计模式，如 AI 生成、工作台、后台、创作工具、计费、上传转化。
- `07-design-review-checklists.md`：用于检验设计是否合理的检查清单。
- `08-design-scoring-system.md`：设计评分体系，用于衡量设计质量和版本对比。
- `09-design-output-templates.md`：统一设计交付模板，包含创新方案、设计评审、页面诊断、任务流、组件清单、AI 生成流程、HTML 原型等。
- `10-post-generation-self-check.md`：生成后自检机制，用于在交付前发现并修正明显问题。
- `11-case-library-template.md`：正面案例、反面案例、行业样本的收集模板。
- `12-excellent-case-library.md`：优秀产品与反面模式案例库，用于设计参照和质量对比。
- `13-nudge.md`：《助推》的选择架构、行为洞察、伦理边界与产品应用。
- `14-source-map.md`：权威资料来源索引。
- `15-ued-ui-visual-review.md`：产品事业部 UED/UIUE 资料的中文执行细化，包含 UI 元素检查、适配、组件选型、走查流程和问题记录模板。
- `16-color-layout-theory.md`：色彩、色系、布局、设计 Token、可访问性、企业系统、移动 App 和数据可视化配色的操作性原则。

## 使用方式

`SKILL.md` 只放核心使用规则和路由。具体场景需要时再读取对应 reference，避免每次都加载过多内容。
