## 4. 建议收集的产品类型

### 工具型产品

关注：

- 快捷操作
- 工作区
- 最近任务
- 模板
- 批量处理
- 自动保存
- 撤销

观察问题：

- 如何让高频操作更近？
- 如何减少用户从零开始？
- 如何让复杂功能不干扰主任务？

### SaaS / B2B 产品

关注：

- 表格
- 筛选
- 权限
- 审批
- 批量操作
- 数据可信度
- 异常处理

观察问题：

- 如何让密集信息可扫描？
- 如何让用户快速定位异常？
- 如何兼顾新手和专家？

### AI 产品

关注：

- 输入设计
- 建议 prompt
- 上下文理解
- 生成反馈
- 引用来源
- 编辑与重试
- 人工接管

观察问题：

- 是否减少输入？
- 是否给用户掌控？
- 是否避免黑箱？

### 内容产品

关注：

- 信息流
- 阅读体验
- 推荐解释
- 收藏
- 搜索
- 继续阅读

观察问题：

- 如何减少选择疲劳？
- 如何让用户知道为什么推荐？
- 如何避免打扰阅读？

### 电商产品

关注：

- 商品比较
- 信任信息
- 价格、库存、评价
- 售后保障
- 下单路径
- 推荐

观察问题：

- 如何帮助用户决策？
- 如何减少风险感？
- 如何避免信息过载？

### 教育 / 学习产品

关注：

- 学习路径
- 进度反馈
- 练习
- 复习
- 激励
- 错题恢复

观察问题：

- 如何让用户知道下一步学什么？
- 如何减少挫败感？
- 如何形成持续反馈？

### 金融 / 医疗 / 高风险产品

关注：

- 信任
- 风险提示
- 审核
- 证据
- 可解释
- 错误恢复

观察问题：

- 如何避免误导？
- 如何让用户理解后果？
- 如何平衡效率与谨慎？

## 5. 设计红线库模板

```text
红线名称：
典型表现：
为什么有害：
违反原则：
替代方案：
适用场景：
```

示例红线：

- 不要用弹窗承载复杂任务。
- 不要把 AI 能力只做成空白聊天框。
- 不要让用户先配置一堆东西才能看到价值。
- 不要用内部术语做导航。
- 不要让颜色承担唯一状态表达。
- 不要为了视觉丰富堆卡片。
- 不要把确认当成唯一防错机制。
